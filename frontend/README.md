# LOOP Frontend

Frontend application for **LOOP - AI Customer Feedback Intelligence Platform**.

Built with **React**, **Vite**, **React Router**, **Bootstrap**, and **Axios**.

---

## Tech Stack

- React
- Vite
- React Router DOM
- Bootstrap
- Axios
- Context API / Redux (Future)

## Getting Started

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
